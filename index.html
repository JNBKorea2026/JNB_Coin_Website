Project Overview

JNB Coin is a BEP-20 compatible standard token project on BNB Chain. It is based on the OpenZeppelin ERC-20 standard structure and prioritizes simplicity and stability.

It does not include additional minting, transaction tax, blacklist, rebase, or auto-liquidity functions.

Representative Use Case

JNB Coin's representative use case is JNB Global Learn & Quiz Reward, an educational, security-awareness, and project-understanding reward program for global users.

The first operation model is automatic scoring, operator approval, and small batch reward distribution. Fully automatic instant reward distribution is suspended until legal, privacy, and security review is completed.

This reward is not an investment event and does not guarantee price increase, profit, exchange listing, exchange registration, or reward approval. The previous AI Career Lecture Reward may remain only as a secondary or separate campaign.
